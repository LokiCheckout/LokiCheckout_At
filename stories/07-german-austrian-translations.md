# German (Austria) translations

As a customer using an Austrian German storefront, I want the Austrian address field labels to be shown in German, so that I understand the address form in my own language.

## Acceptance criteria
- The module ships the translation file `i18n/de_AT.csv`.
- For the locale `de_AT`, the following strings are translated:
  - "Street Name" → "Straße"
  - "Housenumber" → "Hausnummer"
  - "Addition" → "Zusatz"
  - "State/Province" → "Bundesland"
- No other strings are translated by this module.
