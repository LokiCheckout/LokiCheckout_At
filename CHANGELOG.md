## [1.0.0] - 02 June 2026
### Added
- Initial release: Austrian field labels for street, house number, addition, postcode and state in the shipping and billing address
- Austrian 4-digit postcode placeholder and input mask
- `austria` grid layout for country AT
- German (de_AT) translations
- PHP 8.5 support

### Changed
- Use the address-specific and country-specific layout handles for shipping and billing address

### Removed
- PHP 8.1 support
