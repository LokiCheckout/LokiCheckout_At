**This Magento 2 module is an add-on package for the Loki Checkout with country-specific settings for Austria.**

## Installation
Install this package via composer:
```bash
composer require loki-checkout/magento2-at
```

Next, enable this module:
```bash
bin/magento module:enable LokiCheckout_At
```
